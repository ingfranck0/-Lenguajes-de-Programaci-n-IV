PROYECTO BANCO MEXICANO - NETBEANS / JAVA 8

Abrir:
1) Extrae el ZIP.
2) En NetBeans: File > Open Project (Archivo > Abrir proyecto).
3) Selecciona la carpeta BancoMexicano_NetBeans_Maven.
4) Cuando cargue, abre Source Packages > banco.
5) Ejecuta BancoMexicanoApp.java (clic derecho > Run File).

Si no detecta clase principal, en propiedades del proyecto > Run:
Main Class = banco.BancoMexicanoApp

Proyecto Maven con formularios Java Swing. Las opciones Saldo y Salir permanecen
pendientes conforme a la indicación de la actividad.
